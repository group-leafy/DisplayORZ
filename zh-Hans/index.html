DisplayORZ

一款轻量级 macOS 菜单栏工具，只需单击即可软件禁用（软断开）指定的外接显示器——无需拔掉线缆。

为什么选择 DisplayORZ？

与 Windows（提供快捷的 Win + P 切换）不同，macOS 在连接多台显示器时，并没有关闭单个显示器输出的原生方式。系统只提供“扩展显示器”或“镜像显示器”两种选项。

仅仅把显示器的亮度调到零，并不会让它在 macOS 中停用：鼠标指针仍会飘进黑屏，窗口也会继续藏在看不见的空间里。

DisplayORZ 通过底层显示器管理 API 对目标显示器执行软断开来解决这一问题。显示器会立即进入待机状态，macOS 也会自动将所有窗口移回你的活动屏幕。

系统要求

  • macOS：26.3 或更高版本，Apple 芯片

功能特性

  • 一键切换：直接从菜单栏软件禁用或重新启用指定的外接显示器。
  • 光标不再乱飘：禁用显示器后，它会从 macOS 工作区中完全移除——鼠标不会飘进黑屏，窗口也不会凭空消失。
  • 内置安全保护：禁止禁用你唯一的活动显示器或内建屏幕，避免误操作导致无屏可用。
  • 原生且轻量：使用 Swift 与 SwiftUI 构建，内存占用极小，后台零 CPU 开销。
  • 100% 免费：无订阅、无广告、无遥测。

安装方法

  1. 下载最新的 DisplayORZ.dmg。
  2. 将 DisplayORZ.app 拖入「应用程序」文件夹。
  3. 从菜单栏启动应用。
