DisplayORZ

Um utilitário leve para a barra de menus do macOS que permite desativar por software (desconexão lógica) monitores externos específicos com um único clique — sem ter de desligar qualquer cabo.

Transferir DisplayORZ

Porquê o DisplayORZ?

Ao contrário do Windows (que oferece o rápido atalho Win + P), o macOS não dispõe de uma forma nativa de desligar a saída para um único ecrã quando estão ligados vários monitores. O sistema apenas oferece «Ecrã Expandido» ou «Ecrã Espelhado».

Baixar o brilho de um ecrã para zero não o desativa no macOS: o cursor do rato continuará a entrar no ecrã preto e as janelas permanecerão ocultas nesse espaço invisível.

O DisplayORZ resolve-o através de APIs de baixo nível de gestão de ecrãs para desconectar por software os monitores visados. O ecrã entra imediatamente em modo de espera e o macOS relocaliza automaticamente todas as janelas para o seu ecrã ativo.

Requisitos de sistema

  • macOS: 26.3 ou posterior, Apple silicon

Funcionalidades

  • Alternar com um clique: desative ou reative por software monitores externos específicos diretamente a partir da barra de menus.
  • Sem cursores perdidos: ao desativar um monitor, este é removido por completo do seu espaço de trabalho no macOS — sem o rato a desviar-se para o ecrã preto e sem janelas perdidas.
  • Segurança integrada: impede bloqueios acidentais ao bloquear a desativação do seu único ecrã ativo ou do ecrã integrado.
  • Nativo e leve: desenvolvido com Swift e SwiftUI. Utilização mínima de memória e zero consumo de CPU em segundo plano.
  • 100% gratuito: sem subscrições, sem anúncios e sem telemetria.

Instalação

  1. Transfira o DisplayORZ.dmg mais recente.
  2. Arraste o DisplayORZ.app para a pasta Aplicações.
  3. Inicie a aplicação a partir da barra de menus.
