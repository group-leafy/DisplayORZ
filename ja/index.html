DisplayORZ

ケーブルを抜くことなく、ワンクリックで特定の外付けディスプレイをソフト的に無効化（ソフト切断）できる、軽量な macOS メニューバーユーティリティです。

DisplayORZ をダウンロード

DisplayORZ が選ばれる理由

Windows には素早い Win + P による切替がありますが、macOS には複数のモニターを接続しているときに特定のディスプレイへの出力だけをオフにするネイティブな方法がありません。システムが提供するのは「拡張ディスプレイ」または「ミラーリング」だけです。

ディスプレイの明るさをゼロに下げても、macOS 上ではその画面が有効なままです。マウスカーソルは黒い画面に迷い込み、ウィンドウは見えない領域に隠れたままになります。

DisplayORZ は低レベルなディスプレイ管理 API を使って対象モニターをソフト切断することで、この問題を解決します。ディスプレイはすぐにスタンバイ状態へ移行し、macOS が開いているすべてのウィンドウを使用中の画面へ自動的に移動します。

動作環境

  • macOS：26.3 以降、Apple silicon

主な機能

  • ワンクリックで切替：メニューバーから直接、特定の外付けディスプレイをソフト的に無効化／再有効化できます。
  • カーソルの迷い込みなし：ディスプレイを無効化すると、その画面は macOS のワークスペースから完全に除外されます。カーソルが黒い画面に迷い込んだり、ウィンドウが見えない場所に隠れたりすることがありません。
  • 安全機構を内蔵：使用中のディスプレイが 1 台だけの場合や内蔵ディスプレイの無効化をブロックし、誤操作によるロックアウトを防ぎます。
  • ネイティブで軽量：Swift と SwiftUI で構築。メモリ使用量は最小限で、バックグラウンドの CPU 負荷はゼロです。
  • 完全無料：サブスクリプション、広告、テレメトリーは一切ありません。

インストール

  1. 最新の DisplayORZ.dmg をダウンロードします。
  2. DisplayORZ.app を「アプリケーション」フォルダにドラッグします。
  3. メニューバーからアプリを起動します。
