DisplayORZ

케이블을 뽑을 필요 없이, 클릭 한 번으로 특정 외장 디스플레이를 소프트웨어 방식으로 비활성화(소프트 연결 해제)하는 가벼운 macOS 메뉴 막대 유틸리티입니다.

DisplayORZ 다운로드

DisplayORZ를 선택해야 하는 이유

Windows에는 빠른 Win + P 전환이 있지만, macOS에는 여러 대의 모니터를 연결했을 때 특정 디스플레이로의 출력만 끄는 기본 방법이 없습니다. 시스템이 제공하는 옵션은 "확장 디스플레이" 또는 "미러링 디스플레이"뿐입니다.

디스플레이 밝기를 0으로 낮춰도 macOS에서는 여전히 활성 상태로 남아 있습니다. 마우스 커서가 검은 화면 속으로 빠져들고, 보이지 않는 공간에 창이 계속 숨겨져 있게 됩니다.

DisplayORZ는 저수준 디스플레이 관리 API를 사용해 대상 모니터를 소프트 연결 해제함으로써 이 문제를 해결합니다. 디스플레이는 즉시 대기 모드로 전환되고, macOS는 열려 있는 모든 창을 사용 중인 화면으로 자동으로 옮깁니다.

시스템 요구 사항

  • macOS: 26.3 이상, Apple Silicon

주요 기능

  • 원클릭 전환: 메뉴 막대에서 바로 특정 외장 디스플레이를 소프트웨어 방식으로 비활성화하거나 다시 활성화할 수 있습니다.
  • 커서 걱정 없음: 디스플레이를 비활성화하면 해당 화면이 macOS 작업 공간에서 완전히 제거됩니다. 커서가 검은 화면으로 빠져들거나 창을 잃어버릴 일이 없습니다.
  • 기본 안전 장치: 유일하게 사용 중인 디스플레이나 내장 화면은 비활성화할 수 없도록 차단해, 실수로 모든 화면을 잃는 상황을 방지합니다.
  • 네이티브 & 가벼움: Swift와 SwiftUI로 제작되었습니다. 최소한의 메모리 사용량에 백그라운드 CPU 부하가 0입니다.
  • 100% 무료: 구독료도, 광고도, 텔레메트리도 없습니다.

설치 방법

  1. 최신 DisplayORZ.dmg를 다운로드합니다.
  2. DisplayORZ.app을 응용 프로그램 폴더로 드래그합니다.
  3. 메뉴 막대에서 앱을 실행합니다.
