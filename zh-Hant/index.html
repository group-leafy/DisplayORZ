DisplayORZ

一款輕量級 macOS 選單列工具，只需點一下即可透過軟體方式停用（軟性斷開）指定的外接顯示器——不必拔掉任何線材。

為什麼選擇 DisplayORZ？

與 Windows（提供快捷的 Win + P 切換）不同，macOS 在連接多部顯示器時，並沒有關閉單一顯示器輸出的原生方式。系統只提供「延伸顯示器」或「鏡像顯示器」兩種選項。

只是把顯示器的亮度調到零，並不會讓它在 macOS 中停用：滑鼠指標仍會飄進黑畫面，視窗也會繼續藏在看不見的空間裡。

DisplayORZ 透過底層顯示器管理 API 對目標顯示器執行軟性斷開來解決這個問題。顯示器會立即進入待機狀態，macOS 也會自動將所有視窗移回你使用中的螢幕。

系統需求

  • macOS：26.3 或以上版本，Apple 晶片

功能特色

  • 一鍵切換：直接從選單列軟體停用或重新啟用指定的外接顯示器。
  • 滑鼠不再亂飄：停用顯示器後，該螢幕會從 macOS 工作區完全移除——滑鼠不會飄進黑畫面，視窗也不會憑空消失。
  • 內建安全防護：禁止停用你唯一使用中的顯示器或內建螢幕，避免誤操作導致無螢幕可用。
  • 原生且輕量：以 Swift 與 SwiftUI 打造，記憶體占用極小，背景零 CPU 開銷。
  • 100% 免費：沒有訂閱、沒有廣告、沒有遙測。

安裝方式

  1. 下載最新的 DisplayORZ.dmg。
  2. 將 DisplayORZ.app 拖入「應用程式」資料夾。
  3. 從選單列啟動 App。
